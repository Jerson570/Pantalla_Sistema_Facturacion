# Pantalla_Sistema_Facturacion

Proyecto de interfaz gráfica moderna para aplicación de escritorio en C# Windows Forms

## 📌 Descripción del Proyecto
Diseño e implementación de los formularios del sistema de facturación respetando la nomenclatura estándar y la estructura modular planteada en la guía de laboratorio

## 🛠️ Formularios Desarrollados
* **Acceso y Navegación**: `frmLogin`, `frmPrincipal`
* **Tablas**: `frmClientes`, `frmClientesEdicion`, `frmProductos`, `frmCategorias`
* **Facturación**: `frmFacturas`, `frmInformes`
* **Seguridad**: `frmEmpleados`, `frmRoles`, `frmSeguridad`
* **Soporte**: `frmAyuda` (navegación web con `WebBrowser`), `frmAcercaDe`

## ✨ Características Principales
* Menú de navegación horizontal para interacción fluida
* Validación de datos obligatorios en campos clave mediante el componente `ErrorProvider`
* Listados y tablas de visualización visual con `DataGridView`
